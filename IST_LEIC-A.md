# IST Course Projects: LEIC-A / BSc CSE

This is a portfolio of the programming projects I developed for my Bachelor's Degree in Computer Science and Engineering at [Instituto Superior Técnico](https://tecnico.ulisboa.pt/en/), University of Lisbon. Courses with no (existing/relevant) projects are obviously excluded.

I'd never coded before starting this degree, so code quality consistently improves over time. A better representation of my current coding capabilities can be seen on my [Master's degree projects](/IST_MEIC-A.md) and personal projects.

## Year 1

### Year 1, Semester 1

- (P1) **Foundations of Programming** _(Fundamentos da Programação - **FP**)_ - 6.0 ECTS
    - Project: Meadow Simulation (private) [ Python ]  \
      Simulation of a meadow ecosystem in which predators and prey move, feed, reproduce and die over successive generations, built on a set of abstract data types.

- (P2) **Logic for Programming** _(Lógica para Programação - **LP**)_ - 6.0 ECTS
    - Project: [Hashi Puzzle Solver](https://github.com/TiDeane/Hashi-Puzzle-Solver) [ Prolog ]  \
      Prolog program that solves Hashi puzzles, connecting the islands on a grid with the number of bridges each one requires.

### Year 1, Semester 2

- (P1) **Introduction to Algorithms and Data Structures** _(Introdução a Algoritmos e Estruturas de Dados - **IAED**)_ - 6.0 ECTS
    - Project: [Airport System](https://github.com/TiDeane/Airport-System) [ C ]  \
      Flight management system for defining and consulting airports and flights and for making reservations, built on dynamically allocated data structures with manual memory management.

- (P2) **Introduction to Computer Architecture** _(Introdução à Arquitetura de Computadores - **IAC**)_ - 6.0 ECTS
    - Project: [Meteor Rain](https://github.com/TiDeane/Meteor-Rain) [ Assembly ]  \
      Game written in PEPE-16 assembly in which a rover defends a planet, shooting enemy ships and collecting energy from good meteors, using a screen, a keyboard and displays as peripherals.

## Year 2

### Year 2, Semester 1

- (P1) **Object-Oriented Programming** _(Programação com Objectos - **PO**)_ - 6.0 ECTS
    - Project: [Network Application](https://github.com/TiDeane/prr-Network-Application) [ Java ]  \
      Application for managing a network of communication terminals, with registration, management and consultation of clients, terminals and communications.

- (P2) **Operating Systems** _(Sistemas Operativos - **SO**)_ - 6.0 ECTS
    - Project 1: [TécnicoFS](https://github.com/friaes/TecnicoFS) [ C ]  \
      Extensions to a simple user-level file system: symbolic and hard links, copying files in from the host file system, and thread-safe operations.
    - Project 2: [Message Broker](https://github.com/TiDeane/Message-Broker) [ C ]  \
      Publish-subscribe system on top of TécnicoFS: a server process that publisher, subscriber and manager clients connect to through named pipes, storing messages in message boxes.

- (P2) **Analysis and Synthesis of Algorithms** _(Análise e Síntese de Algoritmos - **ASA**)_ - 6.0 ECTS
    - Project 1: [Tiling Combinations](https://github.com/TiDeane/Tiling-Combinations) [ C ]  \
      Counts the number of ways to cover a staircase-bounded area of a grid with square tiles of integer sizes.
    - Project 2: [Adapted Kruskal](https://github.com/TiDeane/Adapted-Kruskal) [ C++ ]  \
      Adapted version of Kruskal's algorithm that finds the maximum value of commercial exchanges between regions in a graph while minimising the number of edges.

### Year 2, Semester 2

- (P3) **Human-Computer Interaction** _(Interação Pessoa-Máquina - **IPM**)_ - 6.0 ECTS
    - Bake-Off 2: [Selection in Dense Interfaces](https://github.com/TiDeane/Dense-Interface-Selection) [ JavaScript ]  \
      Interface designed to minimise selection time among 80 targets, grouped by category and sorted. In the class bake-off it averaged 2.526 seconds per selection.

- (P4) **Databases** _(Bases de Dados - **BD**)_ - 6.0 ECTS
    - Project: [Web App Database Manager](https://github.com/TiDeane/Web-App-Database-Manager) [ SQL, Python, HTML ]  \
      Third part of the course project: integrity constraints, advanced SQL and OLAP queries, and a prototype web app (Python CGI scripts and HTML) for managing products, suppliers, customers and orders.

- (P4) **Artificial Intelligence** _(Inteligência Artificial - **IA**)_ - 6.0 ECTS
    - Project: [Bimaru](https://github.com/TiDeane/Bimaru-Solver) [ Python ]  \
      Solver for Bimaru (Battleship solitaire) puzzles using the ship-based method, with search algorithms adapted from the AIMA codebase.

## Year 3

### Year 3, Semester 1

- (P1) **Computer Organization** _(Organização de Computadores - **OC**)_ - 6.0 ECTS
    - Labs: [Cache Simulation](https://github.com/LC1243/Cache-Simulator) [ C ]  \
      Simulated memory hierarchy with a direct-mapped L1 cache and both direct-mapped and 2-way set-associative L2 caches.

- (P1) **Machine Learning** _(Aprendizagem - **Apre**)_ - 6.0 ECTS
    - Homeworks: [Homeworks](https://github.com/TiDeane/ML-Homeworks)  \
      Four homeworks with pen-and-paper and programming parts: decision trees and evaluation, Bayesian and lazy learning, neural networks and regression, and clustering and PCA.

- (P2) **Computer Networks** _(Redes de Computadores - **RC**)_ - 6.0 ECTS
    - Project: [Auction Server](https://github.com/TiDeane/Auction-Server) [ C ]  \
      Auction platform with a server and a user application communicating over TCP and UDP sockets. Users can open and close auctions, list them and place bids.

### Year 3, Semester 2

- (P3) **Distributed Systems** _(Sistemas Distribuídos - **SD**)_ - 6.0 ECTS
    - Project: [TupleSpaces](https://github.com/TiDeane/TupleSpaces-SD) [ Java, Python, Protobuf ]  \
      Distributed tuple space service using gRPC, in three versions: a single server, three replicas following the Xu-Liskov algorithm, and state machine replication with total ordering of operations.

- (P3) **Software Engineering** _(Engenharia de Software - **ES**)_ - 6.0 ECTS
    - Project: [HumanaEthica](https://github.com/TiDeane/HumanaEthica-ES) [ Java, Groovy, Vue.js, Cypress ]  \
      Features added to HumanaEthica, a platform connecting charities with volunteers, over two agile sprints (backend, then frontend). My subgroup implemented enrollment and applying for an activity, with tests.

- (P4) **Compilers** *(Compiladores - **Com**)* - 6.0 ECTS
    - Project: [TIL Compiler](https://github.com/TiDeane/TIL-Compiler) [ C++, Yacc, Lex ]  \
      Compiler for the TIL language: scanner, parser, type checker, and XML and Postfix code generators, built on the CDK library.

- (P4) **Computer Graphics** *(Computação Gráfica - **CG**)* - 6.0 ECTS
    - Project: Private... [ Three.js ]  \
      Two interactive 3D scenes, each preceded by paper sketches and scene graphs: an articulated crane with fixed and moving cameras, simple animations and collision detection; and a "mathematical carousel" of parametric surfaces with a Möbius strip, materials, lights, textures and a stereoscopic camera.
